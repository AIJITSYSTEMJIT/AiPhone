COOP PWA
This is the iPhone-facing web app shell. It requires an HTTPS backend endpoint at /api/chat that connects securely to Coop/Ollama and the same Coop memory store used by the Windows app.
Do NOT expose Ollama port 11434 directly to the internet.

iPhone install after hosting over HTTPS:
1. Open the Coop HTTPS address in Safari.
2. Share.
3. Add to Home Screen.
4. Turn on Open as Web App.
5. Add.
6. Allow microphone/camera when prompted.
